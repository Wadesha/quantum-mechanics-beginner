# 量子力学入门 · 新手友好路径

> 给"急着抓真谛却被数学劝退"的新手：先走概念门，浅尝数学味道，再被指去正经学习。不速成，也不空谈科幻。

## 它解决什么问题

很多人想学量子力学，但两条路都走不通：

- 直接啃带偏微分方程的教材 → 被数学劝退；
- 只看科幻科普 → 以为懂了，其实满脑子误解。

本项目的核心设计是**把量子力学拆成「概念门」和「形式门」两道门**，让新手从概念门进，在门口浅尝一点数学，再被指去深造。

## 页面结构（单页，可滚动）

| 阶段 | 内容 |
|---|---|
| Stage 0 心态校准 | 它是什么 / 不是什么（3 剂预防针） |
| ① 现象课 | 双缝、光电效应、原子光谱线、黑体辐射（纯概念） |
| ② 思维转换 | 概率本性、不确定性原理（直觉版）、叠加 = 同时的可能性 |
| ③ 极简形式 | 态 = 一支箭头；qubit；玻恩规则（无微积分） |
| 神话粉碎机 | 逐条拆掉科幻误解（观测/纠缠/猫） |
| 术语词典 | 观测、坍缩、概率幅、基、退相干 的准确定义 |
| 深造地图 | 先修数学清单 + 教材路径 |

## 两个交互（纯前端，零依赖）

1. **双缝模拟器**：粒子逐个落屏。关闭"观测"时出现干涉条纹；开启"观测（记录路径）"后干涉消失、只剩两道带——直观演示"观测改变结果"。
2. **Qubit 拖拽 playground**：拖动箭头设定状态 `|ψ⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩`，实时显示 |0⟩/|1⟩ 概率（玻恩规则），可"测量一次"看随机结果。

## PRD · 产品需求文档

> 版本 v0.2 · 状态：单页原型已上线，M2 规划中

### 1. 背景与问题
- **现象**：想自学量子力学的人增长快，但留存极低。
- **两条失败路径**：① 直接啃带偏微分方程的教材 → 被数学劝退；② 只看科幻科普 → 以为懂了，实则误解（超光速、意识坍缩、猫又死又活）。
- **根因**：入口选错。内容要么太重（形式门），要么太虚（伪概念），缺少"概念门优先、再浅尝形式"的中间态。

### 2. 目标用户
| Persona | 画像 | 核心诉求 |
|---|---|---|
| 好奇型新手 | 无/弱理工背景，被科幻吸引 | 快速获得"正确直觉"，不被数学吓退 |
| 转型工程师 | 有编程/基础线代，想入门量子计算 | 低成本建立形式感，知道下一步学什么 |
| 科幻爱好者 | 看过大量科普但概念混乱 | 区分"科幻 vs 现实"，纠正误解 |

### 3. 产品目标
**目标（Goals）**
- 让用户 30 分钟内建立"能搞懂的部分"的正确直觉。
- 用交互把抽象概念变成"可玩、可验证"。
- 清晰指路：从概念门到形式门的下一步路径。

**非目标（Non-goals）**
- 不做速成/应试课程，不承诺"三天精通"。
- 不放完整薛定谔方程推导、希尔伯特空间、算符代数（留到深造）。
- 不做账号系统/付费/社区（当前阶段）。

### 4. 核心价值主张
**概念门优先，形式门浅尝，深造有路。** 既不把问题速成化，也不用科幻概念糊弄——先学友好的部分，浅尝数学味道，再被指去正经学习。

### 6. 内容需求
- **去科幻化**：所有概念可追溯到真实实验或标准理论，禁用"意识坍缩/超光速通信"等夸大表述。
- **微课程**：每篇 ≤300 字 + 1 张图，面向"急着抓真谛"的人。
- **术语词典**：观测/坍缩/概率幅/基/退相干，给教材级准确定义。
- **书单分级**：科普 → 半技术（无微积分）→ 正经教材（如格里菲斯）。

### 7. 非功能需求（NFR）
| 项 | 要求 |
|---|---|
| 性能 | 单文件 < 200KB，首屏无外部请求 |
| 依赖 | 零外部依赖（无 CDN、无字体下载、无地图 SDK） |
| 可访问性 | 对比度达标，交互支持键盘/触屏 |
| 兼容 | 现代浏览器（Chrome/Safari/Edge/Firefox） |
| 部署 | 纯静态，GitHub Pages 直接托管 |

### 8. 信息架构
单页滚动（当前）：Stage 0 → ① 现象课 → ② 思维转换 → ③ 极简形式 → 神话粉碎 → 术语词典 → 深造地图。
未来多页：每个 Stage 独立页 + 首页导航 + 进度追踪。

### 9. 成功度量
- **定性**：用户能口头说清"叠加/坍缩/概率幅"且不带科幻误解。
- **定量**：双缝模拟器观测开关的交互率、滚动到底部（深造地图）的比例、单页平均停留时长。

### 10. 技术约束
- 纯 HTML + CSS + 原生 JS（Canvas），零构建步骤。
- 深色主题，对比度遵循 WCAG AA。
- 发布走 GitHub Contents API，token 仅放 Authorization 头，不进文件/仓库。
